01Run

Network Architecture & Design

Your office or branch network — designed the way it should be, and documented on paper.

What is included

  • Site survey + LAN/WAN design — for a new office or a redesign of an existing setup
  • Structured cabling — Cat6/fiber, proper racking, port labelling
  • VLAN segmentation — office / guest / servers / CCTV each on a separate network
  • Wi-Fi planning — access-point placement based on coverage and capacity, dead zones fixed
  • Dual-ISP setup — load balancing or failover, so if one line drops the other carries on
  • Branch-to-branch connectivity — site-to-site VPN, link redundancy
  • Network documentation — diagram and IP sheet a new engineer can understand in five minutes

When you need it

A new office is being set up, a branch is being added, or Wi-Fi and speed complaints arrive daily.

Hardware Firewall & Network Security

A home router and a business firewall are not the same thing — we close that gap.

What is included

  • Router to proper firewall upgrade (Sophos, FortiGate, pfSense, MikroTik — whichever fits the scope)
  • VPN gateway setup — remote access for WFH and field staff, plus site-to-site
  • Guest network isolation — a visitor’s device cannot reach your office servers
  • Firewall rules and port hardening — only what is necessary stays open
  • Firmware and patch management — security updates on a schedule, never half-done
  • DNS-level filtering — phishing and malware domains blocked before they load
  • Ongoing firewall health check — logs, alerts, quarterly review

When you need it

You are running a plain router, the firewall has never been updated, or there is no secure method for remote access.

Cybersecurity & Data Protection

Ransomware, phishing and data loss — closed down before they become a story your business tells.

What is included

  • Endpoint protection / EDR on every PC and server — managed and monitored, not installed and forgotten
  • Email security and phishing protection — the most common way in, blocked first
  • Ransomware-ready backup — an offline or immutable copy plus a tested restore, so an attack is an inconvenience, not a shutdown
  • Patch and update management on a schedule — never half-done
  • Access hygiene — who can see what, admin rights trimmed, shared passwords retired
  • DNS-level filtering — phishing and malware domains blocked before they load
  • Incident support — if something does break, we investigate first and explain in plain language

When you need it

Everything runs on one shared password, the antivirus expired quietly, or a client asked about your security before signing.
